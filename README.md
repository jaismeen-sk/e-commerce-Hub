# E-commerce Wishlist App

A lightweight front-end e-commerce app that fetches products from the Fake Store API and allows users to save items to a wishlist. The wishlist is stored in the browser using localStorage, so it persists even after page refresh.

## Features

- Browse products from a live API
- Add products to a wishlist
- Remove items from the wishlist
- Wishlist persists across page reloads
- Simple, responsive UI
- No backend or database required

## Tech Stack

- HTML
- CSS
- JavaScript
- Fake Store API
